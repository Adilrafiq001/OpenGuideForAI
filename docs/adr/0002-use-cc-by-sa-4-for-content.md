# ADR 0002: Use CC BY-SA 4.0 for Content

**Date:** 2026-09-28
**Context:** The curriculum content should be openly available but we want to ensure derivative works remain open, and the original creator is properly credited.
**Options:** CC BY 4.0, CC BY-SA 4.0, CC BY-NC 4.0.
**Decision:** CC BY-SA 4.0 with strict mandatory attribution.
**Consequences:** Allows commercial use (good for learners building portfolios/startups) but requires any modified versions of the curriculum to be shared under the same license. **Strict Condition:** Any usage must prominently credit **ARD** as the Architect/Creator, including an "About Me" and portfolio link, ensuring ARD builds their portfolio through this work.
