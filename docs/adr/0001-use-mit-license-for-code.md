# ADR 0001: Use MIT License for Code

**Date:** 2026-09-28
**Context:** OpenGuide AI must be open-source and encourage contributions while protecting the project. We need a permissive license.
**Options:** MIT, Apache 2.0, GPL.
**Decision:** MIT License.
**Consequences:** Easiest for beginners to understand. High adoption rate. No patent retaliation clause like Apache 2.0, but adequate for a static educational app.
