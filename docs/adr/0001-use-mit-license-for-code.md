# ADR 0001: Adopt Sovereign Dual License (AGPL-3.0 for Code, CC BY-NC-SA 4.0 for Curriculum)

**Date:** 2026-10-03  
**Status:** Superseded & Approved (Option A)  
**Context:** OpenGuide must remain free and sovereign forever, preventing third parties from taking the code into proprietary commercial SaaS enclosures or paywalling the educational curriculum without contributing back.  
**Options:**
- Option A: GNU Affero General Public License v3.0 (AGPL-3.0) for code + CC BY-NC-SA 4.0 for curriculum.
- Option B: Apache 2.0 for code + CC BY 4.0 for curriculum.
- Option C: MIT License for code + CC BY-SA 4.0 for curriculum.

**Decision:** Option A — AGPL-3.0 for all software code and CC BY-NC-SA 4.0 for educational curriculum, with mandatory attribution to Adil Rafiq Dar (ARD).  
**Consequences:** Guarantees that any web service or SaaS derived from OpenGuide must remain 100% open source under AGPL-3.0. Protects the curriculum from commercial paywalling, while keeping it free and accessible for learners worldwide.
