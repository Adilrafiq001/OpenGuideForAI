# UX & UI Principles

## 1. Design Principles
- **Clarity over Cleverness:** Interfaces must be intuitive for absolute beginners.
- **Speed:** Zero-to-running-Python in under 2 minutes.
- **Two Lenses:** Every page has a standard view and an "X-Ray Mode" that exposes the underlying architecture, tests, and code for learners.
- **Responsive:** Must work flawlessly on low-end mobile devices and slow networks.

## 2. Accessibility (WCAG 2.2 AA)
- Semantic HTML (nav, main, article, aside).
- High contrast ratios for text and UI elements.
- Full keyboard navigation support (focus states, skip links).
- Screen reader compatibility (ARIA labels where native HTML falls short).

## 3. Component Inventory
- **Code Editor:** Accessible wrapper around Monaco or CodeMirror.
- **Terminal Output:** High-contrast text area for execution results.
- **Progress Map:** Visual skill tree showing tracks and modules.
- **Flashcards:** For spaced repetition and retrieval practice.

## 4. Usability Testing
- We mandate documented usability testing with at least 5 real users (non-coders) for the Track 0 / vertical slice milestone.
