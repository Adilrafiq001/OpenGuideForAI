# Project Constraints

1. **$0 forever:** No paid services, no credit card required for learners or maintainers.
2. **Local-first:** Progress lives in the browser (IndexedDB) by default.
3. **BYOK:** Cloud LLMs use Bring-Your-Own-Key. Keys are never sent to our servers.
4. **No Secrets:** Never commit secrets. Use `.env.example`.
5. **Always-On Project Synchronization:** The entire project MUST remain 100% synchronized in lockstep. Any change to tracks, labs, tools, or themes must be synchronously updated across header, navigation, search modal, portfolio, Bluee AI mentor, and docs.
6. **Mandatory UI/UX Design Engineering Standards:** Always apply `/impeccable`, `/design-taste-frontend`, `/baseline-ui`, `/emil-design-eng`, `/frontend-dev-guidelines`, `/frontend-ui-engineering`, `/react-ui-patterns`, `/magic-ui-generator`, `/uiverse-galaxy`, `/ui-ux-pro-max`, and `/ui-ux-designer`. All dropdowns/modals must have 100% solid, fully opaque backgrounds with zero bleed-through. Header navigation must use cohesive pill architecture.
