# `/resume` Workflow

> **OpenGuide Fast Context Restoration Protocol**  
> *Governing Rule: Restore grounded context from canonical docs and environment state.*

## Execution Steps

1. **Read Canonical Governance**:
   - Read `AGENTS.md` in full to establish project role and constraints.

2. **Read Project State**:
   - Inspect `docs/PROJECT-STATE.md` and `docs/ROADMAP.md` to identify the active phase and recent commits.

3. **Check Environment & Git State**:
   - Run `git status` to check active branch and uncommitted work.
   - Verify local dev server status on `http://localhost:5173`.

4. **Surface Next Objective**:
   - Report active baseline to the user and state the next planned action.
