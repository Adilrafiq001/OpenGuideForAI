# Contributing to OpenGuide AI

Thank you for your interest! We are building a $0, local-first AI education platform.

## Process
1. **Docs First:** All features start with a plan or an ADR.
2. **Small OpenGuide AI Loops:** Keep PRs small and focused.
3. **Tests Required:** No PR is merged without corresponding tests (Playwright/Unit).
4. **Conventional Commits:** We strictly use the Conventional Commits format for PR titles and commit messages.
